# Exploratory evidence, not proof

Before generating the exact formulas, 5,223 distinct triangle-free colourings were sampled and scored by exact fractional-colouring linear programs. None gave both colours below three. Every sampled colouring exposed a three-point `31/10` dual template in one colour, and the complementary five-set supported a monochromatic Petersen graph in that colour. This observation motivated the certified two-lemma decomposition; it is not used as proof.
