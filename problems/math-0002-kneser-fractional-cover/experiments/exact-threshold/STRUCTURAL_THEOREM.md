# Structural theorem under test

The intended centerpiece is not merely the numerical equality `tau_2(KG(8,2))=3`. It is the stronger statement that every triangle-free two-colour edge partition of `KG(8,2)` contains a monochromatic induced Petersen graph, and the same colour then admits an explicit `31/10` fractional-chromatic dual certificate supported by the complementary three-set.

This structural formulation explains the obstruction and is the feature that could make the result mathematically memorable if it certifies and survives external review.
